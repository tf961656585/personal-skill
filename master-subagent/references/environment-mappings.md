# 环境能力映射（按需追加）

SKILL.md 正文只写能力与降级路径。本节记录具体环境中这些能力的注册名；新增环境时只追加条目，不改正文。

## DSH harness（anchored-lean 预设，已实测）

| 能力 | 注册名 / 机制 | 备注 |
|---|---|---|
| 可续委派 | subagent 后台模式，返回子代理句柄 | 子代理结算后运行时发完成通知 |
| 一次性委派 | subagent 同步等待模式 | 返回即结束，不可续跑 |
| 续跑 | send_message（仅直接子级） | 子代理各状态均可作为续跑对象 |
| 中断 | interrupt_agent | 只取消当前轮；深层后代仅可中断 |
| 后代查询 | list_agents（children / descendants） | 不返回自身/父级/兄弟；禁止用于轮询完成 |
| 完成通知 | 运行时在子代理结算后通知父代理 | 与结果返回分离 |
