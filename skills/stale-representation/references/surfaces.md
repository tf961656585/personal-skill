# 载体目录（surfaces）

本文件是 `stale-representation` 的按需查表：给定一个模型可读的载体，查它靠什么绑定主事实、该用什么探针、消费者是谁。

使用规则：

1. 只查与本次改动相关的载体，不逐行通读。
2. 新出现的面必须登记「载体 + 联动 + 探针 + 消费者」；登记不了就标 `unknown`，在返回里列为盲区。
3. 一个载体可以有多条联动，允许多条 record，不强行归一类。
4. 历史注记、已发布版本、生成物本身不算腐化；腐化的是「被当作当前口径」的那部分。

| 代码注释：字面值 | 参数 / 返回值 / 默认值 | copy | `G` | 人 / 模型 | 旧值只出现在历史说明里不算 |

## 常用探针组合

| 场景 | 推荐组合 |
|---|---|
| 改默认值 | `G` 旧值全仓 grep；重点看注释、README 配置表、`.env.example` |
| 改概念名 | `G` 旧词 + 同义词；`R` 术语表、agent-map、文档交叉引用 |
| 删降级路径 | `C` 确认 flag / 分支不存在；`G` runbook、告警处置、回退说明 |
| 升级第三方依赖 | `C` mock / adapter 契约测试；`S` tool schema / 类型；`X` 第三方语义变更 |
| 改工具能力 | `C` 触发干跑 / 样本调用；`R` 注册名、AGENTS、skill frontmatter、memory 钩子 |
| 改数据形状 | `S` schema 校验；`B` seed / 看板 / 缓存重建 |
| 改 UI 行为 | `E` 文案与截图语义比对；视觉验收交 visual-handoff |
