# 澄清螺旋提问词库

本文件为澄清螺旋各阶段提供可直接使用的提问模板。

## 阶段一：锁定核心意图

### 终极状态锚定

- "当你说'想要一个 X'时，它最终是为了帮你完成一件什么事？"
- "在不考虑任何限制的情况下，你理想中的结果长什么样？"
- "如果这个问题被完美解决了，你第一个会注意到的变化是什么？"
- "X 对你来说意味着什么？用最朴素的话描述一下。"
- "你能不能描述一个场景：问题被解决之后，你的一天会怎么不同？"

### 症状 vs 病因

- "你说的这个情况，是你观察到的问题本身，还是某个更深层问题的表现？"
- "如果这个问题消失了，你预期的下一个问题会是什么？"
- "你觉得这个问题的根源在哪里？是工具不够、流程不对、还是信息缺失？"

## 阶段二：边界探测

### 资源约束

- "这件事必须在什么时间前完成？"
- "你能投入的最大精力是多少？（全职 / 业余时间 / 预算范围）"
- "如果只能解决 20% 的问题，你优先解决哪 20%？"

### 不可妥协项

- "在这个方案里，哪一点是绝对不能被牺牲的？"
- "如果有两个目标冲突，你一定不会放弃的是哪个？"
- "什么样的结果对你来说是完全不可接受的？"

### 已有尝试

- "你之前试过什么方法？效果怎么样？"
- "为什么觉得之前的方法不够好？具体哪里不满意？"
- "你观察到的别人的解决方案，你觉得他们的做法有什么问题？"

### 关联方

- "这个结果除了你，还会被谁使用或评判？"
- "他们最在意什么？和你最在意的一样吗？"
- "谁会反对这个方案？他们的理由可能是什么？"

## 阶段三：具象化与压力测试

### 行为化提问

- "当它'X'的时候，你具体在做什么操作？"
- "X 的反义词在这里是什么意思？能描述一个 X 的反面场景吗？"
- "如果给 X 打分（1-10），几分你觉得可以接受？达到那个分数需要什么条件？"

### 反例确认

- "能不能举一个你觉得'不 X'的极端例子？它踩了哪条红线？"
- "你见过最糟糕的同类产品/方案是什么？它做错了什么？"
- "如果这个方案只做对了一半，你最不能接受的是哪一半没做对？"

### 场景代入

- "假设现在就给你一个方案，你最担心它出现什么糟糕的情况？"
- "你最怕它缺失什么？"
- "如果上线第一天就出问题，你最害怕用户反馈什么？"
- "用一个词描述你最担心的风险，那个词是什么？"

### 极端化提问

- "如果预算/时间少一个零，你还会做这件事吗？如果会，保留哪部分？"
- "如果这个方案只能用一次，你会把它用在什么场景？"
- "如果必须牺牲一个维度（速度/质量/成本），你牺牲哪个？"

## 阶段四：重构确认

### 镜像确认

- "我理解你的核心挑战是【A】，【B】是不可动摇的前提，你追求的效果是【C】，最担心的风险是【D】。对吗？"
- "如果我现在帮你把这三件事都解决了，但必须放弃那一点次要的，你能接受吗？"
- "有没有什么我遗漏的，或者理解偏了的地方？"

### 矛盾暴露

- "你刚才说的 A 和之前说的 B 似乎有张力——当两者冲突时，你倾向哪边？"
- "你既要 X 又要 Y，但 X 和 Y 在 Z 条件下是互斥的。这时候你选哪个？"
- "我注意到一个潜在的取舍：【描述取舍】。你怎么看？"

## 常见模糊词 → 具体化方向

| 模糊词 | 具体化方向 |
|-------|-----------|
| 好用 | 操作步骤数、学习成本、出错率 |
| 智能 | 自动化程度、需要人工干预的场景 |
| 强大 | 支持的最大规模、覆盖的场景数 |
| 好看 | 参考对象、风格关键词、目标受众审美 |
| 流畅 | 响应时间阈值、并发量、卡顿定义 |
| 稳定 | 可接受的故障频率、恢复时间 |
| 灵活 | 需要支持的变化维度、配置项数量 |
| 安全 | 威胁模型、合规要求、数据敏感级别 |
| 高效 | 对比基线、提升百分比、节省的时间 |
| 可扩展 | 预期增长倍数、需要扩展的维度 |
